# Rotating Sticky Notes — Home Screens Plugin

Cycles through multiple notes with per-page timing, background color, and text color.

## Features
- Multiple pages with custom duration
- Default or per-note background and text colors (color pickers)
- Simple sticky-note style

## Build
```bash
npm install
npm run build
```

Then copy `manifest.json` and `dist/bundle.js` into your Home Screens plugins folder.
